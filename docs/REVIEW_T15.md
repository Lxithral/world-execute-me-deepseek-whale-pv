## ⚠️ 测量口径 / 未验证

- 电源符号高度是**构造值**（`R = H*0.17`）。我用"中央 36–64% 竖带内亮像素的纵向跨度"去量，得到 **0.75–0.78**，
  但那条带里同时有晶格与线框几何，**量到的不只是符号** —— 所以这个数**不能**当作符号高度的验证，
  符号高度目前只有代码层面的保证。要像素级确认需要单独把符号层渲到空场景。
- `t)`/`b)`/`u)` 未复核（留给 T23）；未跑全量 `?selftest`。

## 🐞 本轮踩的三个真 bug（都已修）

1. 我先在 render 的**时间线常量之前**插入了调用块，却引用了尚未声明的 `tPieces`
   → `Cannot access 'tPieces' before initialization`（TDZ，段 A 每帧抛错，errors=8/34）。改为块内自查一次 `cue('pieces')`。
2. 同一位置调 `drawPowerSymbol(g, …)`，但局部 `const g` 在**更后面**才绑定 → `Cannot access 'g' before initialization`。改用 `ctx.g`。
3. `a_boot.js` **没有导入 `TAU`**，我在两处用了它 → `TAU is not defined`。改用 `Math.PI * 2`。
**教训（与 T11 同源）：往老文件里加代码前，先确认它导入了什么、以及插入点的局部绑定顺序。**
