## ⚠️ doctor 的运行前提（上一轮 CHECKPOINT 没写清，这里补上）

`npm run doctor` 的 **b2（浏览器 import）** 与 **d（`__errors` 为空）** 两项要靠无头 Chrome 打开页面，
**必须先有 dev server 在跑**。没有 server 时 b2/d 会 FAIL（不是 SKIP），容易被误读成代码坏了。

```powershell
# 1) 起 server（后台）
node node_modules/vite/bin/vite.js --port 5173 --host 127.0.0.1
# 2) 再跑 doctor
npm run doctor
```

另外：**不要**把 `npm run doctor` 接在 `| Select-Object -Last N` 后面 —— 该 cmdlet 要收完全部输出才打印，
而 doctor 含 `vite build` + 两次无头 Chrome，会长时间空白、看起来像卡死。直接跑即可。

### ⚠️ 无头 Chrome 需要 full-access（否则 CDP 起不来）

`tools/shoot.mjs` / `tools/selftest.mjs` / `?probe=textscan` 全部依赖 CDP 驱动的无头 Chrome。
Chrome 的 mojo IPC 要开**命名管道**，而 DSH 的 workspace-write 沙箱会拒（实测报
`FATAL:mojo\public\cpp\platform\platform_channel.cc:112 Check failed: 拒绝访问 (0x5)`，
进程直接自终止，CDP 端点无响应）。所以：

- **sandbox = workspace-write** → 只能跑 `npm run doctor` 的 a/b1/c 三项（Node 端）；
- **sandbox = danger-full-access** → 才能跑 b2/d 与所有截图/扫描类验证。

这条不是代码问题，是沙箱边界，写在这里免得下一轮误判成"工具坏了"。
