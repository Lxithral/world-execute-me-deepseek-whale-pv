## 3. 实现要点

- **节点在一个 `InstancedMesh` 里**（5 层 × 14 = 70 个），波前与爆炸只改每实例矩阵 + 实例颜色 → 便宜、无状态累积。
- **连线**用一份 `LineSegments`：层内成环 + 跨层两条（"分层节点 + 连线"）。
- **万花筒**用 3 份 `clone()` 的实例网格（共享几何/材质，各有自己的 `instanceMatrix`），
  每帧把主网格的实例矩阵/颜色 `set()` 过去 —— 于是"同一张网被镜像了"而不是四张不同的网。
- **token 彩纸**每张字形一份 128×64 的 `CanvasTexture`。这张贴图**刻意不走 `text()`**：
  它是装饰粒子、不是面板文字，走 `text()` 只会给 §2.3 的纹理报告添噪声（代码里写明了）。
- **不做相机关键帧**：乐句二的"俯冲"同样是把**网络组**沿 z 往相机推（相对 `ctx.three.camera` 计算），
  与 T04 同一套做法，保证仍是 `t` 的纯函数。
