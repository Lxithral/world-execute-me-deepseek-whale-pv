## ⚠️ T14b **未完成**：0:16/0:18 四角尖峰的根因**未找到**（假设已逐一排除）

现象（240×135 口径，四角各 24×13）：t=15/17/19 四角均值 **0.012–0.025**，而 **t=16.0 = 0.232、t=18.0 = 0.218**
（0.1s 细采样：15.9→0.131、**16.0→0.221**、16.1→0.052，即 ~0.3s 的尖峰；颜色中性灰≈#3a3a3a）。

按追加项的指示**已给 bloom 加上限 0.7**（原式最大 1.31），但**实测四角数值一字未变（仍 0.232/0.218）** → **bloom 不是成因**。
进一步逐一排除（每次只改一个通道再复测同一帧）：

| 假设 | 实验 | 结果 |
|---|---|---|
| bloom 过大 | `Math.min(0.7, 0.36+imp*0.6+burst*0.35)` | **无变化**（0.232/0.218） → 排除 |
| 径向模糊 | `radial: min(0.35, …)`（实验后**已撤回**） | **无变化** → 排除 |
| 曝光关键帧 | 读 `__ctx.exposure`：16.0=**1.502**、18.0=**1.480**（与 17.9/18.1/18.5 的 1.480 **完全相同**） | → 排除 |
| 声明的 fx | `fx.dispersion/glitch/burst/shake` 在 16.0 与 18.0 **全部 = 0.000**（而 16.5 有 disp 0.148/glitch 0.269/shake 0.081，四角却只有 0.018） | → 排除 |

**下一步建议**：既然后处理与 fx 都不是，应查**段 B 场景自身**在该两帧往画面上放了什么
（例如 `ctx.overlay` 全屏叠加、门环/光柱在 16.0 恰好穿过相机、或某个 `hash01(帧号)` 驱动的瞬时亮面），
用 `?only3d=1` / 逐层开关把 2D 与 3D 分开定位。**我没有留下未经验证的改动**（实验性的 `radial` 上限已撤回）。
