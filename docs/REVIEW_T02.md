## 3. 2:52 那一处的根因与修复（已完成）

### 根因：不是残留/曝光/合成层/fog，就是那一条被声明的 flash

480×270 口径实测（`fx.flash(t)` 是页面自己的闪白包络）：

| t | 全帧 mean | 众数颜色 | flash |
|---|---|---|---|
| 171.9 | 0.083 | `0,0,4`（近黑） | 0 |
| **172.0** | **0.444** | **`112,112,112`** | **0.437** |
| 172.1 | 0.157 | `24,24,28` | 0.094 |
| 172.2 | 0.082 | `0,0,4` | 0 |

`l_training.js:33` 写着 `{ t: 171.95, kind: 'flash', amount: 0.6, dur: 0.2 }`。
**`amount` 只有 0.6**，半强度的白色叠在近黑画面上，出来就是**整屏中性灰 #707070** ——
读起来完全像"背景色变成了灰色"，而不是一次闪白（用户原话「应是暗色」，§1.12 同）。

### 修复

**删除该条**（保留紧随其后的 `{t:173.7, kind:'disp'}` 作节拍强调，这一刻不会变空）。
实测修复后 t=172.0 的四角均值 **0.3304 → 0.0076**、`flash=0` ✓。

> 若你希望这里仍有一次**真正的闪白**，做法是改成 `amount: 1.0, dur: 0.08`（纯白且极短，
> 与"半强度灰洗"是两回事）；但它会按"闪白时刻"被自检豁免。代码注释里写了这个备选，等你定。

### 已排除的成因（都有实测依据）

| 候选 | 结论 |
|---|---|
| **闪白（声明）** | `fx.flash(16) = 0`、`fx.flash(18) = 0` → **排除** |
| **fog** | 全仓没有 `THREE.Fog`（只有 `b_dive.js` 的 `fogAt(dist)` 这个 JS 因子函数，不进渲染）→ **排除** |
| **曝光曲线** | 与 `u)` 的 233 点豁免无关；16/18s 不在任何豁免窗口内，而相邻 15/17/19s 均为 0.011–0.045 → 不是慢变的曝光，是 **~0.2s 的尖峰** |
| **合成层 / bloom** | **高度可疑、未坐实**：`main.js:251` 是 `bloom: 0.36 + imp * 0.6 + fx.burst(t) * 0.35`，段 B 是纯器乐、起音密集，强 onset 的 `imp` 会把 bloom 从 0.36 顶到接近 1，叠在暗青底上就是**无色相的整屏泛光 → 中性灰** ✓ 与观测形状（0.2s 尖峰、四角同值）一致 |

**形状**（0.1s 步长）：15.8 → 0.023，15.9 → 0.131，**16.0 → 0.221**，16.1 → 0.052，16.2 → 0.015（≈0.3s 尖峰）；18s 同形（17.9 → 0.133，**18.0 → 0.260**，18.1 → 0.015）。
