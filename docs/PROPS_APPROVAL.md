## 1. 茄子（eggplant）

§1.7 要求的验收点：

- [ ] `LatheGeometry`，轮廓由**样条**给出
- [ ] 球茎最宽处在**下 1/3**，向上收成颈部
- [ ] 长宽比约 **2.6 : 1**
- [ ] 沿一条弧线**整体弯曲 10–18°**
- [ ] **128 径向段 × 96 高度段**（够平滑）
- [ ] `MeshPhysicalMaterial`：深紫**渐变** `#2a0f4a → #4b1d7a`（沿高度）
- [ ] `clearcoat = 1`、`clearcoatRoughness = 0.12`、`roughness = 0.28`
- [ ] `RoomEnvironment` 经 PMREM 作环境光
- [ ] 萼片：**5–7 片弯曲尖瓣**（薄 `ExtrudeGeometry` 并沿长度弯曲），深绿渐变
- [ ] 茎：`TubeGeometry` 沿略弯曲线、由粗到细
- [ ] 半径用低频噪声做 **±2% 不对称**；有纵向高光带

**用户审批：**（请在此行手写 `✅` 或写明打回原因）

## 2. 番茄（tomato）

§1.7 要求的验收点：

- [ ] 扁球，**高:宽 ≈ 0.86**
- [ ] 半径乘 `1 + 0.025·cos(5φ)`，做出 **5–6 个浅浅分瓣**
- [ ] 顶部凹陷、底部小脐
- [ ] 红色渐变（边缘偏橙 `#e8321e`，阴影 `#a30f12`）
- [ ] `clearcoat = 0.9`、`roughness = 0.22`
- [ ] 萼片：**5–6 片**细长弯曲星形绿瓣 + 一小段茎
- [ ] 表面**至多 12 颗**小水珠（小球 + 高光）

**用户审批：**（请在此行手写 `✅` 或写明打回原因）
