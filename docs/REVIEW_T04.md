## 3. 实现要点（为什么这么做）

- **黑洞不用贴图**：奇点 = 纯黑球；光子环 = 加法混合的细 `TorusGeometry`；
  吸积盘 = `RingGeometry` + **自己写的旋涡着色器**（角向条带随半径扭转 + 内热外冷径向衰减 +
  多普勒式一侧增亮）。多普勒那一项是"掠过吸积盘侧面"能读出立体感的关键。
- **相机属于 rig.js**：本文件不新建相机。§1.10 说的"猛推进""甩镜""roll"全部由
  **黑洞组自身的位移/旋转**实现（`position` 相对 `ctx.three.camera` 计算，`yaw/roll` 加在组上），
  这样既不动全片相机关键帧，也仍是 `t` 的纯函数（§0）。
- **石板墙用 InstancedMesh**：24 块共用一份几何/材质，`smash` 只改每实例矩阵 → 便宜且无状态累积。
