### §2.5e 省电

| 子项 | 实现 | 实测 / 说明 |
|---|---|---|
| 暂停时不渲染 | `renderPaused` 守卫（既有） | ✅ 代码路径为 `if (!renderPaused && !hidden) renderAt(t)` |
| 标签页隐藏时不渲染 | 新增 `document.hidden` 守卫 | ⚠️ **本无头环境无法切换页面可见性、也无法在求值里 sleep**，所以只验证了守卫存在与代码路径；未做行为学验证 |
| `?fps=30` | `FPS_CAP`（缺省 0 = 不限）；循环里 `if (fpsCarry < 1/FPS_CAP) return`，**只跳渲染、不跳时钟与调试统计** | ✅ `?fps=30` 下 `__app.fpsCap === 30`。⚠️ SwiftShader 下稳态帧约 **966ms/帧 ≫ 33ms**，上限从不触发，所以**节流行为在本环境不可观测**（真实 GPU 上才有意义） |
| DPR 自适应：连续 1s >25ms 则降 DPR | `loop()` 里的看门狗 → `compositor.setDprScale()`（0.6–1.0，每档 0.2，两次降档间隔 ≥2s） | ✅ **确实触发**：`?perf` 跑到稳态后 `dprScale` 由 1 降到 **0.6**（帧时间 ~1000ms ≫ 25ms）。且加了**前 60 帧预热**：第一版没预热时首帧含着色器编译（实测单帧 **2999ms**）会把 DPR 立刻压到底——那是启动抖动，不是持续过载 |
| `preserveDrawingBuffer` 只在 `?selftest`/`?contact` 开 | 构造处按 URL 参数决定 | ✅ `?selftest` → **true**；`?perf` / `?fps=30` / `?x=…` → **false** |
| （风险核对）关掉后 3D 是否仍能合成进 2D 层 | — | ✅ 仍正常：非自检下把 `#stage` 画进小画布读回，mean **0.0495**、lit **0.647**；页面自报 `px.mean=0.0441`，与改动前完全一致 |
