1. **`rgba is not defined` / `MONO is not defined`**：`c_define.js` 原本只 `import { C }`、用 `text()` 画字，
   **没导入 `rgba` 与 `MONO`**。新标注一用就每帧抛错（errors 一度 **35**，而且 main.js 把
   `ERROR · C` 20px + `rgba is not define` 14px **直接画到了画面上**）。补两个 import 后恢复 `errors=0`。
   （这是本轮**第二次**踩"往老文件加代码前没确认它导入了什么"—— 与 T11 的 `THREE`、T15 的 `TAU` 同源。）

   （原画在 `cy−62`）在两者交叉淡入的那一帧相交。把 `2π` 抬到 `cy − S·0.62` 让开后 **0 重叠**。
