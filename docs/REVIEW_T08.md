## 3. ⚠️ 一处**文档与实测不一致**（重要，请你确认）

§1.12 写「以 back 一词(**2:49.99**)为起点」「**2:51.95** 气泡碎成粒子」。
但**实测锚点**是：

```
give   = 163.609      back = 171.610
prism  = 173.703      trapped = 175.142
```

也就是说 `back` 实测在 **171.610**（= 2:51.61），不是 2:49.99；`prism` 实测 **173.703**，不是 2:51.95。
**但两者的间隔是吻合的**：实测 `prism − back = 2.09s`，§1.12 写的 `2:51.95 − 2:49.99 = 1.96s`。

**我的处理**：按 **§2.2「事件一律来自锚点」**，气泡窗口取 `[back, prism]`（**锚点值**），
而不是文档里的绝对秒数。理由：① 全片其它段落也都是锚点驱动；② 若按绝对秒数，气泡会在
`back` 词**之前**就开始、并在 `prism` 锚点**之前**碎裂 —— 那就与歌词脱钩了。
**如果你要的是绝对秒数（169.99→171.95），请告知**，改成常量即可。

## 4. 实现取舍（写下来免得日后被当成偷工）

- **气泡用「3D 平面 + 贴图」而不是 `ExtrudeGeometry`**：圆角矩形 Shape 在这个尺寸下容易出接缝，
  而贴图方案能把「挤出暗边（右下两层偏移）+ 主体渐变 + 描边 + 尾巴 + 三个点 + 草稿 + 光标」
  一次画准；3D 感由 `rotation.y = −0.18` 的侧转 + 暗边给出。
- **贴图内的草稿文字走裸 `fillText`、不经过 `text()`**：这张 800×300 贴图是**每帧重画**的
  （点要脉冲、草稿要逐字变），若走 `text()`，§2.3 的纹理报告会被 60 次/秒的同名条目淹没。
  字号由本文件自己保证（**84px ≥ 80px**），代码里写明了原因。
- **宽度按相机反算**：`worldW = 0.42·2·halfW`，所以「≥40% 画面宽」是**在屏幕上**成立的，
  换相机也不会失效。
- 旧的 `drawTypingHint()`（一行小字）**已停止调用**，留作死代码并注明"已撤用"。
