## 本轮（FIX_V4）对段 B 的改动与证据

### ✅ §1.3 + §0.2：删除外框小道具与全部标签

- 上一轮按 **FIX_V3 §7 B**「展品用 §5 的 4–12、14、19、20、22，至少 10 种不同模型」
  补过六件（`clock` 钟表 / `toggle` 开关 / `torusknot` 环面结 / `mobius` 莫比乌斯带 /
  `platonic` 正多面体 / `monitor` 终端屏）。**FIX_V4 §1.3 明令删除这六件**，
  §0.4 又规定 FIX_V4 取代 FIX_V3 §7 中 B 的描述 —— 那条"≥10 种"要求**已作废**。
- 已从 `PLAN` / `BUILD` 撤出这六件；`buildBay` 不再被调用
  → 实测 `B.exhibits.filter(e=>e.bay).length` = **0**（**无外框 / 无基座 / 无中文标牌**）。
- 展品数 16 → **10**：`formula, pendulum, lorenz, tesseract, mandelbrot, packet, fourier, galaxy, blackhole, heart`。
- §0.2 要求画面上不得出现任何标签（含中文标签）。实测 t=17/20/24/28 的 stage 文字框 = **0**。
- 六个 builder 作为**死代码**保留在文件里，并在其上方加了醒目注释说明"已作废、下次清理删除"，
  以免被误读成仍在使用的部件。`EX_NAMES` 表同样标注为**不再用于绘制**。
- `errors=0`。

### ✅ §1.2：删除黑色矩形背板

- `src/lib/codewall.js` 的 canvas 底板原来是**不透明**的
  （`g.fillStyle = rgb(5D, 9D, 15D)` + `fillRect` 铺满）。
- 按 §1.2 改为**最多一层 α ≤ 0.12 的暗色渐变**：`BASE_A = clamp(bgAlpha, 0, 0.12)`，
  用 `createLinearGradient` 从 `0.12·D` 渐到 `0.042·D`；深度感改由"**文字颜色乘 `dark`**"承担
  （原来也是这么做的，只是底色顺带一起压暗了）。
- 材质在 R0 已改成 `transparent: true`，所以这里的 alpha 能生效。
- 改动后段 B 实测仍健康：非众数 **42–76%**（器乐门槛 25%）、边缘 **15.4–23.2%**（门槛 4%）、
  过曝 ≤0.25%、`errors=0`；密度比改之前**略升**（少了一块不透明黑板）。

### ✅ 保留：曼德博限曝（R1 早前做的，§1.3 仍要"曼德博缩放（限曝）"）

Reinhard 软限幅 `col/(1+col*0.35)`（峰值 0.98→0.73）。`k` 取 0.35 而非 0.85，因为 §6 还有
"平均亮度 **≥0.10**"的**下限**，压太狠会把整段按到线下。实测 18–24s 过曝 **0.00–0.25%**。
